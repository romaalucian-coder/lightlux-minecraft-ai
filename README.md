LightLux Minecraft AI 🤖💜

An AI Minecraft teammate project built by LightLuxGaming.

The Mission

Build an AI teammate that can:

- Find and join compatible Minecraft Bedrock multiplayer worlds.
- Follow the player and respond to commands.
- Gather resources and help build structures.
- Fight hostile mobs and protect the player.
- Use AI to plan missions and make decisions.

Current Setup

- Player: LucianRoma
- AI teammate: chatgpt_lightlux
- Game: Minecraft Bedrock Edition
- Goal platform: PS5-hosted multiplayer worlds

Development Roadmap

1. Build the AI command and planning system.
2. Choose and test a compatible Bedrock bot connection.
3. Connect the bot to a test world.
4. Add movement, following, gathering, building, and combat.
5. Integrate an AI brain for intelligent decisions.

Important

The project dashboard does not yet connect to Minecraft. A working bot needs a compatible connection and a computer or server to run it. Joining a world hosted by a PS5 must be tested; it is not guaranteed.
